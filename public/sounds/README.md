## Usage Notes

- **Random playback**: Each sound type has `_v1` and `_v2` variations. Randomly pick between them at runtime to avoid repetitive listener fatigue.
- **Layering**: For the core "crack open to reveal soft core" mechanic, layer a main break sound (category 03–05) with a fragment sound (06) and follow with an inner soft sound (07).
- **Build-up sequence**: Press (01) → Micro crack (02) → Main break (03–05) → Fragments (06) → Inner soft (07) → Release (08).
- **Multi-layer shells**: Use category 05 for double/triple layer crispy squishies; combine with 06 fragments for rich shattering experience.
- **Interaction variety**: Use 09 (scrape) for finger dragging on shell surface, 10 (stick) for sticky fillings like caramel or cheese, 11 (special) for themed squishy variants (ice, glass sugar, wafer).
- **Mobile optimization**: All clips are short (1–2s), mono, and lightweight for mobile memory budgets.
