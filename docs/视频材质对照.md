# 小猫参考视频逐帧对照

来源：用户提供的 `脆皮捏捏视频生成 (1).mp4`。以下是视觉观察，不是对实际材料配方或物理参数的测量。

| 时间 | 观察 | 实现要求 |
| --- | --- | --- |
| 0 秒 | 桃粉乳浊蜡面，集中反光，薄边微透，主体不是透明玻璃 | 分离本色与光照，微透射、表面清漆与粗糙度；不能把照片白色高光当作本色 |
| 1.5 秒 | 指腹下凹，长裂口向外延伸，大壳片保留球面曲率 | 开口宽度由局部受力决定；不能均匀张开全部拼块 |
| 3 秒 | 深凹坑，奶油色软芯沿裂口鼓出，断面偏白且细碎 | 凹陷和挤出都必须改变几何；硬壳与软芯不能共用同一种柔软变形 |
| 6 秒 | 换触点后，旧裂口保留；新区域继续破裂 | 损伤与受力历史持久化；壳片倾斜方向跟随首次触点 |
| 7.5 秒 | 深坑与局部压扁，壳片少量脱落，软芯外露 | 可保留形变，不自动复原；最终全部脱壳仍按用户后续明确偏好执行 |

本轮已修改：材质着色只保留原图面部深色图案，移除原图大面积高光；使用实时反射与少量透射；裂边增加长短尺度起伏；壳片首次受力方向固定；硬壳减少随软芯局部拉伸，保留更多原始曲率；修正耳朵轮廓引起的额头放射状几何脊线。

尚未达标：目前仍为固定视角轮廓膨胀模型与预分割断片，不是雕刻模型或动态裂纹拓扑。微透射不等于真实蜡的体积散射。参考中的主裂纹逐段生长、软芯多个褶皱鼓包和断面微细结构仍未完整复现。自动化测试只验证几何与状态正确性，不作为照片级真实度的验收证据。

参考帧位于 `reference-frames/`，编号 0、1、2、4、5 分别对应 0、1.5、3、6、7.5 秒。
